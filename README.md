# Business Accounts — React conversion

This is a Vite + React conversion of the supplied `business-accounts-liquid-glass-pro.html`.

## Included
- React component architecture
- Same liquid-glass / dark-blue visual language and responsive layout
- Journal, Ledger, Trial Balance, P&L, Balance Sheet, Accounts, Info
- INR formatting
- LocalStorage persistence under the original `business-accounts-data` key
- CSV export
- Print statements
- Reset
- Copy/share summary
- Keyboard shortcuts
- Mobile bottom navigation and desktop sidebar
- Orientation/responsive behavior

## Run

```bash
npm install
npm run dev
```

For production:

```bash
npm run build
npm run preview
```
